Technical FAQ & Guide

01 // How do I load and execute an algorithm?

Open the Library view using the toolbar button. Browse our catalog of 40 pre-verified machines, select the one you wish to test, and click Load machine. In the simulation view, enter an initial tape sequence conforming to the active alphabet, then press Start for continuous animation or Step to advance one cycle at a time.

02 // Why did my machine halt unexpectedly?

In deterministic Turing machines, the engine checks the current state and the tape character underneath the read head. If no transition rule is defined in the table for this specific (state, symbol) tuple, execution halts immediately. In classical computability theory, halting represents the intended completion of an algorithm.

03 // How do I back up, export, or share machines?

All custom algorithms are saved in your app's isolated local SwiftData store. You can create portable backups at any time by clicking Export in the toolbar to save standard .json archives. To restore machines on another Mac, use Import.

04 // How does Turingly handle blank tape cells?

The tape is logically infinite in both directions. Unwritten cells are filled with the blank symbol _. You do not need to explicitly declare _ in your alphabet list; the engine automatically handles it as an intrinsic blank marker.

05 // Does Turingly require internet access?

No. Turingly operates 100% offline. It contains no network listeners, no outbound telemetry sockets, and no remote dependencies. All computations and file saves occur strictly on your local Mac.

06 // What should I include in a bug report?

To help resolve issues swiftly, please mention:

  • Your macOS version (e.g. macOS 15.6 Sequoia)
  • Mac model (Apple Silicon or Intel)
  • The algorithm or transition rule causing the problem
  • The starting tape sequence

PRIVACY POLICY
// EFFECTIVE DATE: OCTOBER 20, 2026 • VERSION 1.0

At Turingly, we believe software should respect user sovereignty and privacy by default. Turingly is a standalone, offline deterministic Turing machine simulator built natively for macOS.

01 // Zero Personal Data Collection

Turingly collects, transmits, logs, tracks, and shares ZERO personal data. The application does not include analytics SDKs, advertising beacons, crash report collectors, or any form of telemetry framework.

02 // Local Storage & macOS App Sandbox

All user-authored machines, state transition tables, tape configurations, and computation histories are saved directly into a local SwiftData database housed inside your isolated macOS App Sandbox container.

External disk access occurs solely when you intentionally trigger an Import or Export operation through standard native macOS file open and save panels.

03 // Network Activity

Turingly does not initiate outgoing network connections and does not listen for incoming connections. The app operates with complete fidelity in completely offline environments without internet connectivity.

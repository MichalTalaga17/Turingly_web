Turingly

A native, deterministic Turing machine simulator engineered specifically for macOS. Designed for researchers, educators, students, and engineers seeking visual tape inspection, cycle-by-cycle execution, custom transition table authoring, and complete privacy by default.

01 // Features
Catalog

40 built-in algorithms

An exhaustive curriculum of pre-verified machines spanning foundational tape operations, binary and unary arithmetic (addition, multiplication, two's complement), string manipulation (palindrome detection, parenthesis matching), and classic decision problems.

Execution

Step and continuous run

Inspect state transitions step-by-step with the manual cycle stepper or engage automated continuous simulation with adjustable clock speed. Features immediate deterministic halting detection when no rule matches.

Authoring

Transition table editor

Create and edit custom machines directly through an interactive transition matrix. Turingly automatically indexes states, validates alphabet constraints, and flags incomplete transitions before execution begins.

Storage

Portable archives

Export and import machine configurations and full catalogs using clean, human-readable JSON files. Back up your algorithms and share them with colleagues effortlessly using native macOS file pickers.

System

Native macOS design

Crafted exclusively in Swift and SwiftUI following Apple Human Interface Guidelines. Features native Dark Mode and Light Mode, responsive keyboard shortcuts, and zero non-Apple runtime overhead.

Integrity

Zero data collection

Completely self-contained and sandboxed. Turingly does not contain analytics frameworks, advertising trackers, crash telemetry SDKs, or background network connections. All computation stays on your device.

02 // Privacy
Privacy by design

Zero data collection commitment

Turingly is designed with total privacy as a foundational principle. The application does not collect, record, process, store on external servers, or transmit any personal information, usage metrics, or machine data whatsoever.

Local storage & isolation

All user machines, transition tables, execution histories, and custom tape inputs reside exclusively within the application's local SwiftData store. File interactions (exporting or importing machine archives) take place exclusively through standard macOS open and save dialogs initiated by the user.

03 // Support & contact
Direct developer support

Need technical assistance, have a question regarding Turing machine mechanics, or want to suggest a new algorithm for our library? We provide direct email support for all users.

How do I run a machine?

Open the Library view from the toolbar, pick any of the 40 pre-verified machines, and select Load machine. Input the starting tape symbols conforming to the machine's alphabet, then press Start for automatic execution or Step to step forward one cycle at a time.

Why did the machine halt?

In deterministic Turing machine theory, when the current state and scanned symbol do not match any rule in the transition table, the computation successfully halts. This is the intended termination behavior for all standard algorithms.
